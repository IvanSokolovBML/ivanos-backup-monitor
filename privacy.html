Privacy Policy

Effective date: 19 October 2026.

This policy covers IvanOS Backup Monitor, a personal read-only Google Drive utility operated by its owner, GitHub user IvanSokolovBML, and this informational website.

Data accessed and purpose

With the owner’s authorization, the utility can read Google Drive file metadata (such as names, sizes, timestamps and identifiers) and download encrypted backup archives for local verification. The drive.readonly OAuth scope permits reading all files in the authorized Drive account; application use is limited to checking the owner’s backups. It does not write, upload, modify, or delete Drive files.

Local processing and storage

Verification takes place on the owner’s computer. OAuth credentials, downloaded archives and verification results are private operational data, separate from this public website and its repository. Locally retained files and logs remain under the owner’s control until removed by the owner; this website cannot delete them.

Data sharing and use

Google Drive data is used only for the personal backup verification described here. It is not sold, used for advertising, used to train generalized AI or machine-learning models, or made available to other users. Google handles OAuth authorization and Drive API requests. This public website receives no Drive data or OAuth credentials.

IvanOS Backup Monitor’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Website hosting

These static pages are hosted by GitHub Pages. They contain no analytics, tracking scripts, cookies set by the application, sign-in, or file upload features. GitHub may process technical request information, including IP addresses, to provide and secure hosting under the GitHub Privacy Statement.

Revocation, retention and deletion

The owner can stop the monitor and revoke its Google account access at Google Account connections. Revoking access prevents future authorized access but does not remove files already downloaded. To remove local data, the owner must delete the utility’s stored OAuth credentials, downloaded copies and verification logs from the computer. Original Drive backups remain in the owner’s Drive unless the owner separately deletes them.

Contact and changes

For non-sensitive privacy questions, contact the maintainer through GitHub issues. These are public; do not post private data or credentials. Policy changes will be published on this page with an updated effective date.
