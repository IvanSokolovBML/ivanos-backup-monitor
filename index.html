IvanOS Backup Monitor

A private utility for its owner to check encrypted backup archives stored in the owner’s Google Drive.

What the application does

The monitor reads backup file metadata and, when needed for verification, downloads encrypted archives to the owner’s computer. It helps check that personal backups are present and readable. It is not offered as a public service and does not accept other users.

Why Google Drive access is needed

The application uses Google OAuth with the https://www.googleapis.com/auth/drive.readonly permission. This permission can read and download files across the authorized Drive account; the monitor uses it to inspect the owner’s backups. It does not grant permission to upload, modify, or delete Drive files.

Privacy and control

This website only provides application information. It has no sign-in, upload form, analytics scripts, or access to Google Drive. Backup contents and OAuth credentials are not published here.

Read the Privacy Policy for data handling, retention, and revoking access.

Terms of use

This is a personal utility for its owner only. It is provided as-is, without a service availability or backup recovery guarantee. The owner remains responsible for independent backup and restore checks. This website does not distribute the monitoring application or provide account registration.

Contact

For non-sensitive questions, contact the maintainer through the project’s GitHub issues. Issues are public: never include backup data, tokens, credentials, or personal files.
